# MM-14 command reference

Generated by `mm_14 --commands` from the dispatch table; do not edit by hand.

Stack pictures read left to right, deepest first: `y x -- result` means
Y and X are consumed and `result` is left in X.

## Stack

| Command | Stack | Description |
|---|---|---|
| `dup` | `a -- a a` | duplicate X |

| `2dup` | `a b -- a b a b` | duplicate the top pair |
| `2drop` | `a b --` | discard the top pair |
| `clx` | `x -- 0` | clear X to zero |
| `clst` | `... --` | clear the whole stack |
| `lstx` | `-- last_x` | recall X before the last operation |
| `lsty` | `-- last_y` | recall Y before the last binary operation |
| `stacksize` | `-- n` | number of items on the stack (alias of depth) |

| `stack>stat` | `... -- n` | feed all items into the statistics as x values and clear the stack |
